# 青栏 Qinglan 投诉举报入口

> 本文档随系统实现同步更新。本文档汇总用户可用的投诉、举报与申诉入口，说明各入口的适用场景、处理流程与响应时限，以及人工联系渠道。文中入口路径与系统当前实现一致；联系地址为占位样式，由校方在备案时填写实际地址。

## 一、站内举报入口

### 1.1 举报帖子

**入口**：帖子详情页的"举报"按钮。

**适用场景**：帖子存在广告推广、色情低俗、辱骂与人身攻击、泄露他人隐私、诈骗与欺诈、违法违规、与话题无关等情形。

**操作方式**：点击"举报"后选择违规类型，可选填写补充说明后提交。举报人的身份取自你的登录态。

### 1.2 举报评论

**入口**：评论条目上的"举报"按钮。

**适用场景**：评论存在上述违规情形。

### 1.3 举报的规则与限制

- 举报入口仅对**已认证并处于可用状态**的用户开放，游客与未认证用户无法举报；
- 你**不能举报自己的内容**；
- 你**不能举报对自己不可见的内容**（待审帖子、已下架且非你本人的帖子及其评论）；
- 对同一目标**每个用户只能举报一次**，重复举报会被系统明确拒绝，而不是静默忽略；
- 举报后你会收到处置结果的站内通知（举报被采纳或未被采纳）。

### 1.4 举报的处理流程

```
提交举报 → 去重 → 按目标聚合成"待处理举报数" → 进入管理端审核队列
                                                    │
   帖子待处理举报数达到 3 条 → 系统自动下架该帖 → 转人工复核
                                                    │
                              管理员处置：维持下架 / 驳回举报 / 移除评论
                                                    │
                                       逐条通知各自的举报人
```

- 审核队列按**待处理举报数 + 等待时长**排序，举报多、等待久的优先处置；
- 帖子被自动下架**不等于**举报成立：举报会保留待处理状态，由人工复核后决定维持还是驳回，举报不成立的帖子会被恢复。

## 二、对处置结果不服：申诉

**入口**：帖子详情页的"提交申诉"（仅当帖子处于下架状态时，对作者显示）。

**适用场景**：你是帖子的作者，且帖子被下架。

**规则**：

- 仅**被下架的帖子**可以申诉，其余处置不受理申诉；
- 申诉人必须是帖子作者本人；
- **时限**：自下架时刻起 **7 日**内提交，超期不再受理；
- **次数**：**每帖限一次**，重复提交会被拒绝；
- **复审人**：由**另一位管理员**复审，原处置人不得复审自己处置过的内容；
- **结果**：申诉通过则帖子恢复可见，不通过则维持原判；两种结果都会通过站内通知告知你。

## 三、人工联系渠道

以下渠道由校方在备案时填写实际地址与电话。在填写完成前，用户可通过平台公示的运营方联系方式反映问题。

| 用途 | 联系渠道 | 说明 |
| --- | --- | --- |
| 举报与投诉受理 | `qinglan-support@<校方域名>` | `由校方在备案时填写实际地址` |
| 个人信息查询 / 更正 / 注销申请 | `qinglan-support@<校方域名>` | 同上，需核验身份 |
| 违规内容紧急处置 | `____________________（由校方备案时填写值班电话）` | 用于紧急、高风险内容的快速处置 |
| 受理时间 | `工作日上午 ____ 至下午 ____（由校方备案时填写）` | 非工作时段提交的问题于下一个工作日处理 |

提交人工投诉时，请尽量提供：问题描述、涉及的帖子或评论、你的账号标识、事情经过与时间，以便核实。

## 四、响应时限

平台结合自动化水平作出如下时限承诺，该承诺依赖运营方在工作时段安排审核人员值守：

| 事项 | 时限 |
| --- | --- |
| 举报首次处置 | 目标 **30 分钟内**完成首次处置（举报进入队列后按举报数与等待时长排序，积压条目在管理端标记提示） |
| 帖子举报数达 3 条自动下架 | **自动、即时**发生，无需人工介入；人工复核随后跟进 |
| 申诉提交 | 系统即时受理，复审结果通过站内通知送达 |
| 人工投诉 | 工作日内受理，具体答复时间视核实复杂度而定 |
| 紧急违规内容 | 由值班渠道优先处置 |

## 五、注意事项

- 请勿滥用举报功能。恶意、重复或虚假举报不仅会被系统去重，情节严重时可能被计入信用分扣减或账号处置。
- 举报他人时请勿在举报补充说明中再次传播违规内容本身；如涉及隐私信息，平台会按内部流程处理。
- 平台对举报人的身份保密，被举报人无法得知举报人是谁。
