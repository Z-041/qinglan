# 青栏 Qinglan 隐私政策

> 本文档随系统实现同步更新。本政策说明青栏（Qinglan）在提供服务过程中收集哪些个人信息、收集的目的、存储与保护方式、对外可见范围，以及你可以如何行使自己的权利。政策中的技术措施均与系统当前实现一致。

## 一、适用范围

本政策适用于本校在校学生使用青栏平台的全过程，包括身份认证、发帖、评论、点赞、举报、申诉、查看联系方式等行为，以及游客浏览行为。

## 二、我们收集哪些信息、为什么收集

平台遵循最小化收集原则，只收集提供服务所必需的信息：

| 信息 | 收集时点 | 用途 | 是否对外可见 |
| --- | --- | --- | --- |
| 校园邮箱 | 认证时 | **仅用于**一次性发送验证码，并判定你的本校身份 | 否 |
| 学号 | 认证时 | **仅用于**"一人一学号"绑定，保证一人一校 | 否 |
| 匿名盐值 | 认证时由系统生成 | 派生你的匿名代号 | 否（不对任何接口返回明文） |
| 发布内容 | 发帖 / 评论时 | 提供社区服务 | 是（审核通过后对认证用户公开） |
| 联系方式 | 你主动填写时 | 供其他认证学生与你联系 | 仅认证学生可见 |
| 行为记录 | 使用过程中 | 点赞、举报、查看联系方式等操作的留痕与审计 | 举报人身份不对外；查看联系方式的行为仅用于内部追溯 |

平台**不收集**以下信息：通讯录、位置、设备通讯信息、支付信息（平台不提供付费功能）、生物特征信息（平台不做人脸识别）。

## 三、存储与保护

### 3.1 学号：加密存储

学号以 **AES-256-GCM** 加密后写入数据库，每次加密使用随机初始向量，同一学号两次加密结果不同，无法被直接比对。解密能力仅用于依法配合有权机关调查的专用通道；该通道**不接入任何管理后台、日志或导出功能**，运营管理员在日常管理界面中无法查看学号明文。

### 3.2 邮箱：不可逆哈希存储

校园邮箱以 SHA-256 加固定 salt（pepper）哈希后入库，数据库内不保存邮箱明文，无法从库中反推邮箱地址。哈希所用的 pepper 长期保持不变，以保证历史数据的匹配一致性。

### 3.3 密钥管理

- 加密密钥、哈希用 pepper、JWT 签名密钥一律通过**环境变量**注入，不写入代码仓库、不写入配置文件、不写入日志；
- 数据库连接的口令同样通过环境变量提供；
- 身份字段的加密与解密逻辑集中在独立组件中，避免散落调用。

### 3.4 传输与接口

- 所有对外接口的出入参均为数据传输对象，不直接序列化数据库实体；
- 身份字段在任何对外接口中都不会以明文或密文形式返回。

## 四、对外不可见范围（硬性边界）

以下约束由系统结构保证，不是依靠管理员自觉：

1. **管理界面不返回身份信息**：管理端的用户列表只包含用户标识、角色、账号状态、信用分、封禁到期时间与注册时间，**不包含**邮箱、学号明文或密文。管理接口与其他接口复用同一份对外档案结构。
2. **日志不打印敏感信息**：系统日志不打印手机号、学号、Token 等敏感内容；错误信息不回显内部堆栈、SQL 或身份数据。
3. **导出功能受限**：查询类接口必须分页并做权限校验，禁止无限制的全表扫描与身份字段导出。
4. **管理员角色与普通用户角色隔离**，管理接口默认拒绝未授权访问。

## 五、你的匿名性

- 你在帖子中展示的匿名代号由系统按 `hash(帖子 ID + 作者 ID + 你的专属盐值)` 派生。**同一用户在不同帖子下的代号必然不同，任何人都无法通过对比代号将你在不同帖子中的发言关联起来**；平台对外接口不会同时返回你的代号与你的账号标识。
- **举报人身份不对外**：举报记录中会保存举报人，该信息仅用于举报去重与处置结果反馈的投递，不出现在审核队列及其他任何对外数据中，被举报人无法得知举报人是谁。
- 匿名保护的是你在其他用户面前的隐私。平台在你认证时保有认证记录，当且仅当依法配合有权机关调查时，才通过专用通道核验身份。

## 六、联系方式的可见性

联系方式是最需要谨慎对待的字段，其可见性由**服务端**判定，不是前端隐藏：

- **可见条件（两个条件须同时满足）**：
  1. 作者本人主动在联系方式字段中填写了内容；
  2. 访问者已通过校园身份认证。
- **游客与未认证用户**：接口返回的联系方式字段为 `null`，页面上看不到，也无法通过抓包获取明文。
- **被处置时**：若帖子被管理员执行"隐藏联系方式"处置，联系方式**仅作者本人可见**，其他认证用户同样看不到；处置被撤销后恢复正常可见。
- **查看留痕**：认证用户查看他人联系方式时，系统会记录查看者与查看时间，用于追溯恶意批量抓取行为；作者本人查看自己的帖子不产生该记录。

## 七、审计与留存

- 下架、恢复、封禁、隐藏联系方式、公告发布、查看联系方式等管理动作会写入审计日志；
- 审计日志**只增不改不删**，系统不提供修改或删除审计记录的接口；
- 审计日志保留期不少于 6 个月，用于内容处置的存证与追溯。

## 八、你的权利

### 8.1 查询与更正

你可以通过站内"个人中心"查看自己的账号状态、信用分与发布记录。若发现学号绑定、邮箱等认证信息有误，请通过本目录《05-投诉举报入口》所述的渠道提出更正申请。

### 8.2 注销账号

平台当前未提供自助注销入口。如需注销账号，请通过《05-投诉举报入口》所述的渠道提出申请，由运营方核验身份后人工处理。请注意：

- 注销将导致账号不可恢复，已发布的内容是否一并删除以处理时的告知为准；
- 依法应当留存的审计日志与违法信息处置记录，不因注销而删除。

### 8.3 投诉

若你认为平台处理个人信息的行为侵害了你的权益，可通过《05-投诉举报入口》所述的渠道提出投诉。

## 九、政策更新

本政策随系统实现同步更新。当收集范围、用途或保护措施发生实质变化时，政策将同步修订，并通过公告告知用户。
