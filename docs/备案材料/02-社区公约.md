# 青栏 Qinglan 社区公约

> 本文档随系统实现同步更新。本公约面向本校认证学生，说明在本平台发布与互动时应遵守的规则、平台鼓励与禁止的行为，以及违规后将实际发生的后果。公约中描述的每一项处置都在系统中真实实现，不是倡导性表述。

## 一、适用范围

本公约适用于所有通过校园身份认证、可使用青栏发布与互动功能的本校学生。游客与未认证用户只能浏览已审核通过的内容，不适用发布类规则。

使用本平台即表示你已阅读并同意本公约。平台保留依据本公约及相关法律法规处置违规内容的权利。

## 二、我们鼓励什么

- **真实、有用的校园信息**：失物招领、二手闲置、拼车拼团、问答互助、活动信息、合理范围内的校园生活吐槽。
- **理性、就事论事的表达**：对事不对人，讨论问题而非攻击个人。
- **善用举报**：看到违规内容时通过举报入口反馈，而不是在评论区对骂或扩散。举报是平台事后治理的主要信息来源。

## 三、我们禁止什么

### 3.1 系统会直接拦截，无法发布

以下内容在你点击发布时即被拒绝，不会进入平台：

- **身份证号、银行卡号**：系统内置隐私信息识别规则，正文或联系方式中命中即拒绝发布，提示你修改后再试。这是为防止个人敏感信息泄露所做的硬性拦截，无法绕过。
- **命中敏感词库的内容**：系统内置本地敏感词库，命中即拒绝发布。

请在发布前自行检查，不要在正文或联系方式字段中夹带上述信息——两个字段都会被同样检查，不存在"正文干净、联系方式里夹带"的绕过路径。

### 3.2 法律与校纪禁止的内容

- 色情低俗内容；
- 辱骂、人身攻击、网络暴力；
- 泄露他人隐私（未经同意发布他人姓名、学号、手机号、宿舍、行程等）；
- 诈骗、欺诈、虚假兼职与虚假交易信息；
- 其他违反法律法规与校纪校规的内容；
- 广告、推广、刷屏等与话题无关的内容。

上述内容若通过机制审核进入平台，一经举报核实，将按下文规则处置。

## 四、匿名不等于免责

### 4.1 前台的匿名机制

你在帖子中展示的是一个随机匿名代号。该代号由系统按 `hash(帖子 ID + 作者 ID + 你的专属盐值)` 派生，因此**你在不同帖子下的代号必然不同，任何人都无法通过对比代号把你在不同帖子中的发言关联起来**。平台对外接口不会同时返回你的代号与你的账号标识。

### 4.2 后台可追溯，且仅在依法配合调查时启用

匿名保护的是你在其他用户面前的隐私，不是对平台、对法律的责任豁免：

- 发布任何内容前，你必须先通过校园邮箱与学号认证，平台保有认证记录；
- 学号以 AES-256-GCM 加密存储，运营管理员在管理后台**看不到**你的真实身份；
- 当且仅当依法配合有权机关的调查时，才通过专用通道核验身份，该通道不接入任何管理后台、日志或导出功能。

请把匿名理解为"对同学匿名"，而不是"对规则匿名"。发布前请设想：这条内容若必须由你本人署名，你还愿意发吗？

## 五、联系方式规则

二手交易、失物招领、拼车拼团等场景需要留联系方式，平台允许在帖子的联系方式字段中填写，但**请谨慎对待**：

- 联系方式字段与正文分开存储，独立于正文管理；
- 联系方式**只对已认证的本校学生可见**。游客与未认证用户看到的该字段为空，这不是前端隐藏，而是服务端根本不返回；
- 被查看会**留下查看记录**（谁在何时查看了哪条帖子的联系方式），用于追溯恶意批量抓取；
- 若你的帖子被判定存在诈骗、联系方式滥用等风险，管理员可执行"隐藏联系方式"处置，此时联系方式**仅你本人可见**，其他认证用户也看不到；处置被撤销后恢复正常可见。

请勿在联系方式字段中填写他人的联系方式，也勿填写身份证、银行卡等敏感号码。

## 六、违规后果

平台的实际处置手段如下，会按违规性质与情节选择适用：

| 处置 | 对你和其他用户的影响 |
| --- | --- |
| 驳回 | 帖子处于待审阶段时未通过审核，帖子不会对其他用户可见，你会收到驳回理由 |
| 下架 | 帖子对其他用户不可见，你自己仍可打开查看；可申诉 |
| 隐藏联系方式 | 帖子本身仍可见，但联系方式仅你本人可见 |
| 移除评论 | 违规评论被移除 |
| 信用分扣减 | 信用分初始为 100，违规会被扣减 |
| 限时封禁 | 账号在封禁期内无法发布与互动，到期自动恢复 |
| 黑名单 | 严重失信的账号进入黑名单，需人工解除 |

### 6.1 信用分与发帖门槛（硬性机制）

**信用分低于 60 分时，你将无法发布帖子**，系统在发布前会直接拦截。信用分初始为 100，违规由管理员依规则扣减；如认为扣分有误，可依据《05-投诉举报入口》提出更正申请，由管理员核实后调整。

### 6.2 自动下架（无需管理员介入）

帖子发布后，若有 **3 条待处理的举报**累积到该帖上，系统会**自动将帖子下架**并转入人工复核，同时通知你。这意味着恶意举报可能误伤正常内容，因此所有举报都会进入人工队列二次确认；确认举报不成立的，帖子会被恢复。

### 6.3 封禁

封禁有明确期限，到期自动恢复；情节严重或累犯的，会由管理员处以更长期限的封禁，或列入黑名单。

## 七、举报、申诉与你的权利

- **举报**：你可以在帖子详情页或评论上使用"举报"入口，选择举报理由（广告推广、色情低俗、辱骂攻击、泄露隐私、诈骗、违法违规、与话题无关、其他）并可补充说明。**同一用户对同一目标只能举报一次**，重复举报会被系统拒绝。你不能举报自己的内容。
- **申诉**：若你的帖子被下架，你可以在**下架之日起 7 日内**，在帖子详情页提交申诉（**每帖限一次**）。申诉将由**另一位**管理员复审，原处置人不得复审自己的裁决。复审结果会通知你：申诉通过的帖子恢复可见，未通过的维持原判。
- **查看处置记录**：审核结果与举报反馈会通过站内通知送达。若你对处置有疑问，可通过本目录《05-投诉举报入口》所述渠道联系管理方。

## 八、公约的更新

本公约随系统实现同步更新。系统功能或处置规则发生实质变化时，公约将同步修订并通过公告告知用户。
