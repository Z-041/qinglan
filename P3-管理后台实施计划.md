# P3 管理后台 实施计划

> 依据 spec：[P3-管理后台设计方案.md](./P3-管理后台设计方案.md)
> 规范：AGENTS.md（冲突时以它为准）
>
> 执行说明：本文件按任务顺序执行，每个任务结束提交一次。步骤用 `- [ ]` 勾选跟踪。

**Goal:** 交付一个仅面向 PC 的管理后台，使 P2 已具备的审核能力可操作化，并补齐用户治理与运营看板。

**Architecture:** 后端只新增 3 个接口（用户列表 / 审核上下文 / 看板统计），其余全部复用 P2 成果；跨模块聚合放 `review` 模块（白名单里唯一能同时读 post/comment/user 的模块）。前端在同一个 Vite 应用内新增 `/admin` 路由子树，Element Plus 按需自动导入，学生端 bundle 不受影响。

**Tech Stack:** Java 21 / Spring Boot 3.5 / Spring Data JPA / MySQL 8；Vue 3 + TS + Vite 6 + UnoCSS + Element Plus + Pinia + Vitest。

```java
    private Long createUserAt(String emailHash, String studentIdHash, String isoInstant) {
        User saved = userRepository.saveAndFlush(newUser(emailHash, studentIdHash));
        jdbcTemplate.update("update user set created_at = ? where id = ?",
                java.sql.Timestamp.from(java.time.Instant.parse(isoInstant)), saved.getId());
        // JdbcTemplate 绕过 JPA，一级缓存里的实体仍是旧时间。不清空的话，下面查回来的是内存中
```

`UserRepository` 增加（补 import `org.springframework.data.domain.Pageable`、`org.springframework.data.jpa.repository.Query`、`org.springframework.data.repository.query.Param`、`java.time.Instant`、`java.util.List`、`UserRole`、`UserStatus`）：

```java
    /**
     * 管理端用户列表：键集分页 + 可选筛选。
     *
     * <p>排序键 {@code (created_at desc, id desc)}，游标是这两列的复合值；四个比较条件必须与
     * {@code order by} 严格同序。首页传 {@code cursorCreatedAt = null}，由第一个分支恒真兜住，
     * 因此首页与后续页共用同一条查询，不必维护两份近乎相同的 JPQL。</p>
     *
     * <p>刻意不提供身份维度（邮箱 / 学号）的查询条件：两者都是哈希或密文存储，按它们检索会
     * 形成「探测某学号是否存在」的侧信道（不变量 #3 的精神）。</p>
     *
     * <p>必须给 {@code Pageable}：管理端全量用户是无界集合，安全红线禁止无限制全表扫描。</p>
     */
    @Query("""
            select u from User u
            where (:status is null or u.status = :status)
              and (:role is null or u.role = :role)
              and (:minCredit is null or u.creditScore >= :minCredit)
              and (:maxCredit is null or u.creditScore <= :maxCredit)
              and (:createdFrom is null or u.createdAt >= :createdFrom)
              and (:createdTo is null or u.createdAt <= :createdTo)
              and (:cursorCreatedAt is null
                   or u.createdAt < :cursorCreatedAt
                   or (u.createdAt = :cursorCreatedAt and u.id < :cursorId))
            order by u.createdAt desc, u.id desc
            """)
    List<User> findAdminPage(
            @Param("status") UserStatus status,
            @Param("role") UserRole role,
            @Param("minCredit") Integer minCredit,
            @Param("maxCredit") Integer maxCredit,
            @Param("createdFrom") Instant createdFrom,
            @Param("createdTo") Instant createdTo,
            @Param("cursorCreatedAt") Instant cursorCreatedAt,
            @Param("cursorId") Long cursorId,
            Pageable limit);
```

```java
    private static final int DEFAULT_PAGE_SIZE = 20;
    private static final String KEY_SEPARATOR = ":";
    /** 游标段数：注册毫秒 : 用户 id */
    private static final int CURSOR_SEGMENTS = 2;
```

在 `toProfile` 附近新增方法：

```java
    /**
     * 管理端用户列表：键集分页，多取一条判断是否还有下一页，避免额外 count 查询。
     *
     * <p>不提供身份维度检索（理由见 {@code UserRepository#findAdminPage}）。</p>
     */
    @Transactional(readOnly = true)
    public CursorPage<UserProfileResponse> listUsers(AdminUserQuery query) {
        AdminUserCursor cursor = parseCursor(query.cursor());
        List<User> rows = userRepository.findAdminPage(
                query.status(), query.role(), query.minCredit(), query.maxCredit(),
                query.createdFrom(), query.createdTo(),
                cursor.createdAt(), cursor.id(),
                PageRequest.of(0, DEFAULT_PAGE_SIZE + 1));

        boolean hasMore = rows.size() > DEFAULT_PAGE_SIZE;
        List<User> page = hasMore ? List.copyOf(rows.subList(0, DEFAULT_PAGE_SIZE)) : rows;
        if (page.isEmpty()) {
            return CursorPage.empty();
        }
        List<UserProfileResponse> items = page.stream().map(this::toProfile).toList();
        String nextCursor = hasMore ? formatCursor(page.get(page.size() - 1)) : null;
        return CursorPage.of(items, nextCursor);
    }

    private AdminUserCursor parseCursor(String raw) {
        if (raw == null || raw.isBlank()) {
            return new AdminUserCursor(null, null);
        }
        String[] parts = raw.split(KEY_SEPARATOR);
        if (parts.length != CURSOR_SEGMENTS) {
            throw new BizException(ErrorCode.CURSOR_INVALID);
        }
        try {
            return new AdminUserCursor(Instant.ofEpochMilli(Long.parseLong(parts[0])), Long.parseLong(parts[1]));
        } catch (NumberFormatException ex) {
            throw new BizException(ErrorCode.CURSOR_INVALID);
        }
    }

    private String formatCursor(User last) {
        return last.getCreatedAt().toEpochMilli() + KEY_SEPARATOR + last.getId();
    }

    }
```

```java
import com.qinglan.common.audit.AuditLog;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.Repository;
import org.springframework.data.repository.query.Param;

/**
 * 审核上下文的跨表聚合。
 *
 * <p>为什么声明在 {@code review}：查询要同时碰审计表与帖子/评论，而 AGENTS.md 第三章白名单里
 * 只有 {@code review} 能同时读 {@code post} / {@code comment}；{@code common} 不得反向依赖业务模块。</p>

 * delete / update 入口（不变量 #7）。</p>

public interface ReviewContextRepository extends Repository<AuditLog, Long> {

                    and l.targetId in (select p.id from Post p where p.authorId = :authorId))
                or (l.targetType = com.qinglan.common.audit.AuditTargetType.COMMENT
                    and l.targetId in (select c.id from Comment c where c.authorId = :authorId)))
            """)
    long countAuthorViolations(@Param("authorId") Long authorId);
```

```java
package com.qinglan.review.service;

import com.qinglan.comment.entity.Comment;
import com.qinglan.comment.repository.CommentRepository;
import com.qinglan.common.error.BizException;
import com.qinglan.common.error.ErrorCode;
import com.qinglan.post.entity.Post;
import com.qinglan.post.repository.PostRepository;
import com.qinglan.review.dto.AdminReviewContextResponse;
import com.qinglan.review.entity.Report;
import com.qinglan.review.entity.ReportReason;
import com.qinglan.review.entity.ReportStatus;
import com.qinglan.review.entity.ReviewTargetType;
import com.qinglan.review.repository.ReportRepository;
import com.qinglan.review.repository.ReviewContextRepository;
import com.qinglan.user.entity.User;
import com.qinglan.user.service.UserService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

/**
 * 审核上下文面板：按目标反查作者与举报聚合。
 *
 * <p>为什么按 target 反查而不是从队列带过来：{@code ReviewQueueItemResponse} 刻意不含
 * {@code authorId}（不变量 #1 的引申，已有测试断言）。作者 id 只在本方法内部流转，
 * 出参里只有信用分与违规次数，不出现任何身份字段。</p>
 */
@Service
@RequiredArgsConstructor
public class ReviewContextService {

    private final PostRepository postRepository;
    private final CommentRepository commentRepository;
    private final UserService userService;
    private final ReportRepository reportRepository;
    private final ReviewContextRepository reviewContextRepository;

    @Transactional(readOnly = true)
    public AdminReviewContextResponse context(ReviewTargetType targetType, Long targetId) {
        Target target = resolveTarget(targetType, targetId);
        User author = userService.requireById(target.authorId());

        List<Report> pending = reportRepository.findByTargetTypeAndTargetIdAndStatus(
                targetType, targetId, ReportStatus.PENDING);
        List<Long> reporterIds = reportRepository.findDistinctReporterIds(targetType, targetId);
        long repeated = reporterIds.isEmpty()
                ? 0L
                : reportRepository.countReportersWithOtherReports(reporterIds, targetType, targetId);
        List<ReportReason> reasons = pending.stream().map(Report::getReasonCode).distinct().toList();

        return new AdminReviewContextResponse(
                targetType,
                targetId,
                target.status(),
                author.getCreditScore(),
                reviewContextRepository.countAuthorViolations(target.authorId()),
                pending.size(),
                reporterIds.size(),
                repeated,
                reasons);
    }

    private Target resolveTarget(ReviewTargetType targetType, Long targetId) {
        return switch (targetType) {
            case POST -> postRepository.findById(targetId)
                    .map(post -> new Target(post.getAuthorId(), post.getStatus().name()))
                    .orElseThrow(() -> new BizException(ErrorCode.POST_NOT_FOUND));
            case COMMENT -> commentRepository.findById(targetId)
                    .map(comment -> new Target(comment.getAuthorId(), comment.getStatus().name()))
                    .orElseThrow(() -> new BizException(ErrorCode.COMMENT_NOT_FOUND));
        };
    }

    /** 内部值对象：{@code authorId} 不出本类 */
    private record Target(Long authorId, String status) {
    }
}
```

```java
package com.qinglan.review.service;

import com.qinglan.common.audit.AuditLogRepository;
import com.qinglan.post.entity.PostStatus;
import com.qinglan.post.repository.PostRepository;
import com.qinglan.review.dto.AdminStatsResponse;
import com.qinglan.review.entity.AppealStatus;
import com.qinglan.review.entity.ReportStatus;
import com.qinglan.review.repository.AppealRepository;
import com.qinglan.review.repository.ReportRepository;
import com.qinglan.user.entity.UserStatus;
import com.qinglan.user.repository.UserRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;
import java.time.LocalDate;
import java.time.ZoneId;
import java.util.ArrayList;
import java.util.List;

/**
 * 运营看板。
 *
 * <p>全部为计数聚合，逐条走带条件的 count 查询；「近 7 日」按 Asia/Shanghai 的自然日边界
 * 逐日查 7 次，无数据的日期补 0，保证前端永远拿到固定 7 项。</p>
 */
@Service
@RequiredArgsConstructor
public class AdminStatsService {

    /** 日界线时区：与管理员的直觉一致，不用 UTC */
    private static final ZoneId STATS_ZONE = ZoneId.of("Asia/Shanghai");
    private static final int RECENT_DAYS = 7;

    private final PostRepository postRepository;
    private final ReportRepository reportRepository;
    private final AppealRepository appealRepository;
    private final UserRepository userRepository;
    private final AuditLogRepository auditLogRepository;

    @Transactional(readOnly = true)
    public AdminStatsResponse overview() {
        LocalDate today = LocalDate.now(STATS_ZONE);
        Instant todayStart = startOfDay(today);
        Instant tomorrowStart = startOfDay(today.plusDays(1));

        AdminStatsResponse.ContentStats content = new AdminStatsResponse.ContentStats(
                postRepository.count(),
                postRepository.countByStatusIn(List.of(PostStatus.PENDING, PostStatus.REVIEWING)),
                postRepository.countByStatus(PostStatus.TAKEN_DOWN),
                postRepository.countByCreatedAtGreaterThanEqualAndCreatedAtLessThan(todayStart, tomorrowStart));

        AdminStatsResponse.ModerationStats moderation = new AdminStatsResponse.ModerationStats(
                reportRepository.countByStatus(ReportStatus.PENDING),
                appealRepository.countByStatus(AppealStatus.PENDING),
                auditLogRepository.countByCreatedAtGreaterThanEqualAndCreatedAtLessThan(todayStart, tomorrowStart),
                recentDaysHandled(today));

        AdminStatsResponse.UserStats users = new AdminStatsResponse.UserStats(
                userRepository.count(),
                userRepository.countByStatusIn(List.of(UserStatus.BANNED, UserStatus.BLACKLISTED)),
                userRepository.countByCreatedAtGreaterThanEqualAndCreatedAtLessThan(todayStart, tomorrowStart));

        return new AdminStatsResponse(content, moderation, users);
    }

    private List<AdminStatsResponse.DailyCount> recentDaysHandled(LocalDate today) {
        List<AdminStatsResponse.DailyCount> days = new ArrayList<>(RECENT_DAYS);
        for (int offset = RECENT_DAYS - 1; offset >= 0; offset--) {
            LocalDate day = today.minusDays(offset);
            long count = auditLogRepository.countByCreatedAtGreaterThanEqualAndCreatedAtLessThan(
                    startOfDay(day), startOfDay(day.plusDays(1)));
            days.add(new AdminStatsResponse.DailyCount(day, count));
        }
        return List.copyOf(days);
    }

    private Instant startOfDay(LocalDate day) {
        return day.atStartOfDay(STATS_ZONE).toInstant();
    }
}
```

```java
package com.qinglan.review.service;

import com.qinglan.common.error.BizException;
import com.qinglan.common.error.ErrorCode;
import com.qinglan.common.web.CursorPage;
import com.qinglan.post.entity.Post;
import com.qinglan.post.repository.PostRepository;
import com.qinglan.review.dto.AdminAppealItemResponse;
import com.qinglan.review.entity.Appeal;
import com.qinglan.review.entity.AppealStatus;
import com.qinglan.review.repository.AppealRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

/**
 * 待复审申诉队列：供管理端工作台逐条复审（设计书第 113 行「换管理员复审」）。
 *
 * <p>只列 {@code PENDING}，按申诉时间升序（先到先审）。与 {@link ReviewQueueService} 同构：
 * 排序与分页交给数据库，一页之内用一次批量查询补齐帖子摘要，杜绝逐行查询造成的 N+1。</p>
 *
 * <p>队列里不出现申诉人的任何信息——申诉人就是作者，作者身份不出队列（不变量 #1 的引申）。</p>
 */
@Service
@RequiredArgsConstructor
public class AppealQueueService {

    private static final int DEFAULT_PAGE_SIZE = 20;
    private static final int PREVIEW_LENGTH = 80;
    private static final String ELLIPSIS = "...";
    private static final String KEY_SEPARATOR = ":";
    /** 游标段数：申诉毫秒 : 申诉 id */
    private static final int CURSOR_SEGMENTS = 2;

    private final AppealRepository appealRepository;
    private final PostRepository postRepository;

    @Transactional(readOnly = true)
    public CursorPage<AdminAppealItemResponse> queue(String cursorRaw) {
        AppealCursor cursor = parseCursor(cursorRaw);
        // 多取一条判断是否还有下一页，避免额外 count 查询
        List<Appeal> rows = appealRepository.findAdminPage(AppealStatus.PENDING,
                cursor.createdAt(), cursor.id(), PageRequest.of(0, DEFAULT_PAGE_SIZE + 1));

        boolean hasMore = rows.size() > DEFAULT_PAGE_SIZE;
        List<Appeal> page = hasMore ? List.copyOf(rows.subList(0, DEFAULT_PAGE_SIZE)) : rows;
        if (page.isEmpty()) {
            return CursorPage.empty();
        }

        Map<Long, Post> posts = loadPosts(page);
        List<AdminAppealItemResponse> items = page.stream()
                .map(appeal -> toItem(appeal, posts.get(appeal.getTargetId())))
                .toList();
        String nextCursor = hasMore ? formatCursor(page.get(page.size() - 1)) : null;
        return CursorPage.of(items, nextCursor);
    }

    // ---------------------------------------------------------------- 内部方法

    private Map<Long, Post> loadPosts(List<Appeal> page) {
        List<Long> ids = page.stream().map(Appeal::getTargetId).distinct().toList();
        return postRepository.findAllById(ids).stream()
                .collect(Collectors.toMap(Post::getId, post -> post));
    }

    private AdminAppealItemResponse toItem(Appeal appeal, Post post) {
        return new AdminAppealItemResponse(
                appeal.getId(),
                appeal.getTargetType(),
                appeal.getTargetId(),
                preview(post == null ? null : post.getContent()),
                post == null ? null : post.getStatus().name(),
                post == null ? null : post.getReviewReason(),
                appeal.getReason(),
                appeal.getCreatedAt());
    }

    private String preview(String content) {
        if (content == null) {
            return null;
        }
        return content.length() <= PREVIEW_LENGTH ? content : content.substring(0, PREVIEW_LENGTH) + ELLIPSIS;
    }

    /**
     * 解析游标。游标对客户端不透明，只要求原样回传；格式为「申诉毫秒:申诉 id」，
     * 两段必须齐全且为正数，缺段、错位或非数字一律按非法游标拒绝。
     */
    private AppealCursor parseCursor(String raw) {
        if (raw == null || raw.isBlank()) {
            return new AppealCursor(null, null);
        }
        String[] parts = raw.split(KEY_SEPARATOR);
        if (parts.length != CURSOR_SEGMENTS) {
            throw new BizException(ErrorCode.CURSOR_INVALID);
        }
        try {
            long millis = Long.parseLong(parts[0]);
            long id = Long.parseLong(parts[1]);
            if (millis <= 0 || id <= 0) {
                throw new NumberFormatException("游标各段不合法");
            }
            return new AppealCursor(Instant.ofEpochMilli(millis), id);
        } catch (NumberFormatException ex) {
            throw new BizException(ErrorCode.CURSOR_INVALID);
        }
    }

    private String formatCursor(Appeal appeal) {
        return appeal.getCreatedAt().toEpochMilli() + KEY_SEPARATOR + appeal.getId();
    }

    /** 申诉队列游标：与 {@link AppealRepository#findAdminPage} 的排序键逐一对应 */
    private record AppealCursor(Instant createdAt, Long id) {
    }
}
```

```ts
 * 仅 src/api 内部使用：所有 HTTP 请求都必须经由此处。
```

```vue
/** 与后端 qinglan.auth.code-ttl 默认值保持一致，仅用于文案提示 */
const CODE_TTL_MINUTES = 5

/** 管理后台的准入角色（spec D3：REVIEWER 本轮不放行） */
const ADMIN_ROLES: UserRole[] = ['ADMIN', 'SUPER_ADMIN']

/**
 * 执行认证动作，失败返回 null。
 * 错误提示已由 http 拦截器统一弹窗（AGENTS.md 第七章），这里只判断是否成功以决定推进。
 */
async function attempt<T>(action: () => Promise<T>): Promise<T | null> {
  try {
    return await action()
  } catch {
    return null
  }
}

function targetPath(): string {
  const redirect = route.query.redirect
  return typeof redirect === 'string' && redirect.startsWith('/admin') ? redirect : '/admin/dashboard'
}

async function handleSendCode(): Promise<void> {
  if ((await attempt(() => requestCode(email.value.trim()))) === null) {
    return
  }
  code.value = ''
  step.value = 'code'
}

async function handleVerify(): Promise<void> {
  const result = await attempt(() => verify(email.value.trim(), code.value.trim()))
  if (result === null) {
    return
  }
  if (result.needsStudentBinding) {
    userStore.signOut()
    pushToast('该邮箱尚未绑定学号，无法登录管理后台', 'error')
    return
  }
  if (!userStore.profile || !ADMIN_ROLES.includes(userStore.profile.role)) {
    // 学生账号可能被用来试后台：必须清干净登录态，不能把令牌留在本地
    userStore.signOut()
    pushToast('该账号没有管理后台权限', 'error')
    return
  }
  void router.replace(targetPath())
}
```

```ts
import { ref } from 'vue'

import { fetchAdminReviewQueue } from '@/api/review'
import type { AdminQueueItem } from '@/types/review'

/**
 * 首报距今超过该小时数即视为超时，行内标红。
 * 后端 qinglan.review 只有 autoTakeDownThreshold 与 appealWindow，没有等待时长阈值，
 * 不为此新增后端配置（spec 5.4），故定为前端常量。
 */
export const REPORT_OVERDUE_HOURS = 24

const MILLIS_PER_HOUR = 3_600_000

/** 首报时间是否已超时。now 可注入，便于测试 */
export function isReportOverdue(firstReportedAt: string, now: number = Date.now()): boolean {
  return now - new Date(firstReportedAt).getTime() > REPORT_OVERDUE_HOURS * MILLIS_PER_HOUR
}

/**
 * 管理端举报队列：游标分页 + 刷新。
 * 排序（举报数降序 + 等待时长升序）完全由后端负责，前端不再排序。
 */
export function useReviewQueue() {
  const items = ref<AdminQueueItem[]>([])
  const loading = ref(false)
  const loadingMore = ref(false)
  const hasMore = ref(false)

  /** 不放进 ref：只作为下一次请求的入参，变化不需要触发渲染 */
  let cursor: string | null = null

  function applyPage(page: { items: AdminQueueItem[]; nextCursor: string | null }, append: boolean): void {
    items.value = append ? [...items.value, ...page.items] : page.items
    cursor = page.nextCursor
    hasMore.value = page.nextCursor !== null
  }

  /** 处置成功后重拉第一页（spec 5.5：局部刷新，不整页 reload） */
  async function refresh(): Promise<void> {
    loading.value = true
    try {
      applyPage(await fetchAdminReviewQueue(null), false)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loading.value = false
    }
  }

  async function loadMore(): Promise<void> {
    if (!hasMore.value || loading.value || loadingMore.value) {
      return
    }
    loadingMore.value = true
    try {
      applyPage(await fetchAdminReviewQueue(cursor), true)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loadingMore.value = false
    }
  }

  return { items, loading, loadingMore, hasMore, refresh, loadMore }
}
```

```ts
import { ref } from 'vue'

import { fetchAdminReviewContext } from '@/api/review'
import type { AdminReviewContext, ReviewTargetType } from '@/types/review'

export interface ReviewTarget {
  targetType: ReviewTargetType
  targetId: number
}

/**
 * 上下文面板的数据源：按 target 反查。
 * 队列响应刻意不含作者与举报人身份，作者信息只能这样按目标取（spec 7.3）。
 */
export function useReviewContext() {
  const target = ref<ReviewTarget | null>(null)
  const context = ref<AdminReviewContext | null>(null)
  const loading = ref(false)

  async function open(next: ReviewTarget): Promise<void> {
    target.value = next
    context.value = null
    loading.value = true
    try {
      context.value = await fetchAdminReviewContext(next.targetType, next.targetId)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loading.value = false
    }
  }

  function close(): void {
    target.value = null
    context.value = null
  }

  /** 处置完成后刷新面板（信用分、举报数等会变） */
  async function reload(): Promise<void> {
    if (target.value) {
      await open(target.value)
    }
  }

  return { target, context, loading, open, close, reload }
}
```

```ts
import { ref } from 'vue'

import {
  acceptAppeal,
  approvePost,
  dismissReports,
  hidePostContact,
  rejectAppeal,
  rejectPost,
  removeComment,
  restorePost,
  showPostContact,
  takeDownPost,
  upholdReports,
} from '@/api/review'
import type { DismissReportsPayload, ReasonPayload, TakeDownPayload } from '@/types/review'

/**
 * 处置动作编排：把「提交中」状态与「成功 / 失败」语义收在一处，
 * 视图只关心成功后做什么（刷新列表、关闭面板）。
 * 失败一律由 http 拦截器提示，这里不重复渲染文案。
 */
export function useReviewActions() {
  const submitting = ref(false)

  async function run(action: () => Promise<void>): Promise<boolean> {
    submitting.value = true
    try {
      await action()
      return true
    } catch {
      // 错误已由拦截器提示
      return false
    } finally {
      submitting.value = false
    }
  }

  return {
    submitting,
    approvePost: (postId: number) => run(() => approvePost(postId)),
    rejectPost: (postId: number, payload: ReasonPayload) => run(() => rejectPost(postId, payload)),
    takeDownPost: (postId: number, payload: TakeDownPayload) => run(() => takeDownPost(postId, payload)),
    restorePost: (postId: number, payload: ReasonPayload) => run(() => restorePost(postId, payload)),
    hidePostContact: (postId: number, payload: ReasonPayload) => run(() => hidePostContact(postId, payload)),
    showPostContact: (postId: number, payload: ReasonPayload) => run(() => showPostContact(postId, payload)),
    removeComment: (commentId: number, payload: ReasonPayload) => run(() => removeComment(commentId, payload)),
    dismissReports: (payload: DismissReportsPayload) => run(() => dismissReports(payload)),
    upholdReports: (postId: number, payload: ReasonPayload) => run(() => upholdReports(postId, payload)),
    acceptAppeal: (appealId: number, payload: ReasonPayload) => run(() => acceptAppeal(appealId, payload)),
    rejectAppeal: (appealId: number, payload: ReasonPayload) => run(() => rejectAppeal(appealId, payload)),
  }
}
```

```vue
async function runReasonAction(action: ReviewAction, targetId: number, payload: ReasonPayload): Promise<boolean> {
  switch (action) {
    case 'reject':
      return rejectPost(targetId, payload)
    case 'restore':
      return restorePost(targetId, payload)
    case 'uphold':
      return upholdReports(targetId, payload)
    case 'hide-contact':
      return hidePostContact(targetId, payload)
    case 'show-contact':
      return showPostContact(targetId, payload)
    case 'remove-comment':
      return removeComment(targetId, payload)
    default:
      return false
  }
}

async function handleAction(action: ReviewAction): Promise<void> {
  const current = target.value
  if (!current) {
    return
  }
  const targetId = current.targetId

  if (action === 'approve') {
    if (await approvePost(targetId)) {
      await afterHandled('已通过')
    }
    return
  }
  if (action === 'take-down') {
    takeDownOpen.value = true
    return
  }
  if (action === 'dismiss') {
    dismissOpen.value = true
    return
  }

  const meta = REASON_ACTIONS[action]
  if (!meta) {
    return
  }
  const reason = await promptReason(meta.title)
  if (reason === null) {
    return
  }
  if (await runReasonAction(action, targetId, { reason })) {
    await afterHandled(meta.success)
  }
}

async function handleTakeDown(payload: TakeDownPayload): Promise<void> {
  const current = target.value
  if (!current) {
    return
  }
  if (await takeDownPost(current.targetId, payload)) {
    await afterHandled(payload.banDays ? '已下架并封禁作者' : '已下架')
  }
}

async function handleDismiss(reason: string): Promise<void> {
  const current = target.value
  if (!current) {
    return
  }
  const payload = { targetType: current.targetType, targetId: current.targetId, reason }
  if (await dismissReports(payload)) {
    await afterHandled('已驳回举报')
  }
}
```

```ts
import { ref } from 'vue'

import { fetchAdminAppeals } from '@/api/review'
import type { AdminAppealItem } from '@/types/review'

/**
 * 待复审申诉队列：FIFO（后端按 created_at asc 排，先到先审），游标分页。
 * 队列里没有申诉人字段——申诉人就是作者，作者身份不出队列（不变量 #1 引申）。
 */
export function useAppealQueue() {
  const items = ref<AdminAppealItem[]>([])
  const loading = ref(false)
  const loadingMore = ref(false)
  const hasMore = ref(false)

  /** 不放进 ref：只作为下一次请求的入参，变化不需要触发渲染 */
  let cursor: string | null = null

  function applyPage(page: { items: AdminAppealItem[]; nextCursor: string | null }, append: boolean): void {
    items.value = append ? [...items.value, ...page.items] : page.items
    cursor = page.nextCursor
    hasMore.value = page.nextCursor !== null
  }

  /** 复审成功后重拉第一页，已复审的不再出现（后端只返回 PENDING） */
  async function refresh(): Promise<void> {
    loading.value = true
    try {
      applyPage(await fetchAdminAppeals(null), false)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loading.value = false
    }
  }

  async function loadMore(): Promise<void> {
    if (!hasMore.value || loading.value || loadingMore.value) {
      return
    }
    loadingMore.value = true
    try {
      applyPage(await fetchAdminAppeals(cursor), true)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loadingMore.value = false
    }
  }

  return { items, loading, loadingMore, hasMore, refresh, loadMore }
}
```

> **状态分档的边界**：后端封禁接口只有 `POST /users/{id}/ban`，它固定落到 `BANNED`（`User.banUntil`），本轮没有任何接口能把用户置为 `BLACKLISTED`（spec 4.1 接口总览里没有，7.6「本轮不做角色管理界面」同源）。因此本页只提供「封禁（→ BANNED）/ 解封（→ ACTIVE）/ 调分」，`BLACKLISTED` 只在状态列与筛选项里如实展示。

```ts
import { ref } from 'vue'

import { adjustCredit, banUser, fetchAdminUsers, unbanUser } from '@/api/admin'
import type {
  AdminUserItem,
  AdminUserQuery,
  BanUserPayload,
  CreditAdjustPayload,
  UserFilterState,
} from '@/types/admin'
import type { ReasonPayload } from '@/types/review'

/** 筛选表单初值：全部不限 */
export function createEmptyFilters(): UserFilterState {
  return {
    status: '',
    role: '',
    minCredit: '',
    maxCredit: '',
    createdFrom: '',
    createdTo: '',
  }
}

/** 空串视为「不限」，转成 null；非法数字也当「不限」处理，不把 NaN 发给后端 */
function toNumberOrNull(value: string): number | null {
  const trimmed = value.trim()
  if (!trimmed) {
    return null
  }
  const parsed = Number(trimmed)
  return Number.isInteger(parsed) ? parsed : null
}

/** datetime-local 是本地时间且不带时区，后端要的是 Instant，故转成 ISO-8601 UTC */
function toInstantOrNull(value: string): string | null {
  const trimmed = value.trim()
  if (!trimmed) {
    return null
  }
  const parsed = new Date(trimmed)
  return Number.isNaN(parsed.getTime()) ? null : parsed.toISOString()
}

/** 表单状态 → 请求参数。规范化只此一处，视图不做转换 */
export function toQuery(filters: UserFilterState, cursor: string | null): AdminUserQuery {
  return {
    cursor,
    status: filters.status || null,
    role: filters.role || null,
    minCredit: toNumberOrNull(filters.minCredit),
    maxCredit: toNumberOrNull(filters.maxCredit),
    createdFrom: toInstantOrNull(filters.createdFrom),
    createdTo: toInstantOrNull(filters.createdTo),
  }
}

/**
 * 用户管理：组合筛选 + 游标分页 + 行内处置。
 * 只支持状态 / 角色 / 信用分 / 注册时间筛选，不做身份搜索（spec 7.2 隐私侧信道）。
 */
export function useUserManage() {
  const filters = ref<UserFilterState>(createEmptyFilters())
  const items = ref<AdminUserItem[]>([])
  const loading = ref(false)
  const loadingMore = ref(false)
  const hasMore = ref(false)
  const submitting = ref(false)

  /** 不放进 ref：只作为下一次请求的入参，变化不需要触发渲染 */
  let cursor: string | null = null

  function applyPage(page: { items: AdminUserItem[]; nextCursor: string | null }, append: boolean): void {
    items.value = append ? [...items.value, ...page.items] : page.items
    cursor = page.nextCursor
    hasMore.value = page.nextCursor !== null
  }

  /** 查询第一页。筛选条件变化后必须走这里，否则游标仍指向旧条件的结果集 */
  async function refresh(): Promise<void> {
    loading.value = true
    try {
      applyPage(await fetchAdminUsers(toQuery(filters.value, null)), false)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loading.value = false
    }
  }

  async function loadMore(): Promise<void> {
    if (!hasMore.value || loading.value || loadingMore.value) {
      return
    }
    loadingMore.value = true
    try {
      applyPage(await fetchAdminUsers(toQuery(filters.value, cursor)), true)
    } catch {
      // 错误已由拦截器提示
    } finally {
      loadingMore.value = false
    }
  }

  /** 清空筛选并回到第一页 */
  async function reset(): Promise<void> {
    filters.value = createEmptyFilters()
    await refresh()
  }

  /** 处置动作的统一收尾：成功返回 true；失败只复位 submitting，错误由拦截器提示 */
  async function run(action: () => Promise<void>): Promise<boolean> {
    submitting.value = true
    try {
      await action()
      return true
    } catch {
      return false
    } finally {
      submitting.value = false
    }
  }

  return {
    filters,
    items,
    loading,
    loadingMore,
    hasMore,
    submitting,
    refresh,
    loadMore,
    reset,
    ban: (userId: number, payload: BanUserPayload) => run(() => banUser(userId, payload)),
    unban: (userId: number, payload: ReasonPayload) => run(() => unbanUser(userId, payload)),
    adjustCredit: (userId: number, payload: CreditAdjustPayload) => run(() => adjustCredit(userId, payload)),
  }
}
```

```vue
import BaseButton from '@/components/base/BaseButton.vue'
import BaseTextarea from '@/components/base/BaseTextarea.vue'
import FormField from '@/components/base/FormField.vue'
```

```vue
function handleSubmit(): void {
  if (!canSubmit.value) {
    return
  }
  emit('submit', deltaValue.value, reason.value.trim())
}
```

**Files:**

- [ ] **Step 1: 重写 `src/router/index.ts`**

三处关键设计（spec 5.3 / 7.4）：

1. `requiresAdmin` 挂在父路由 `/admin` 上——vue-router 会把各级 `matched` 记录的 `meta` 合并进 `to.meta`，子路由无需逐条重复；
2. `/admin/login` **不设 `guestOnly`**：与学生端 `/login` 同设会让两页互相弹走（都判定「已登录则回首页」），与「重定向环防护」相悖；
3. 非管理员访问 `/admin/**` → 提示 + 回首页，**不再跳 `/admin/login`**，避免与学生端登录页来回跳。

```ts
import { createRouter, createWebHistory } from 'vue-router'

import { useAuth } from '@/composables/useAuth'
import { pushToast } from '@/composables/useToast'
import { useUserStore } from '@/stores/user'
import type { UserRole } from '@/types/user'

declare module 'vue-router' {
  interface RouteMeta {
    /** 需要登录后才能访问 */
    requiresAuth?: boolean
    /** 已登录用户不应再访问（如认证页） */
    guestOnly?: boolean
    /**
     * 需要管理员角色（ADMIN / SUPER_ADMIN）。
     * 未登录 → 管理端登录页；已登录但非管理员 → 提示后回首页。
     */
    requiresAdmin?: boolean
  }
}

/** 管理后台的准入角色（spec D3：REVIEWER 本轮不放行） */
const ADMIN_ROLES: UserRole[] = ['ADMIN', 'SUPER_ADMIN']

function isAdmin(role: UserRole | null | undefined): boolean {
  return role !== null && role !== undefined && ADMIN_ROLES.includes(role)
}

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', name: 'home', component: () => import('@/views/HomeView.vue') },
    {
      // 只接受数字 id：否则 /posts/abc 会被视图 Number() 成 NaN 再拿去请求接口
      path: '/posts/:id(\\d+)',
      name: 'post-detail',
      component: () => import('@/views/PostDetailView.vue'),
    },
    {
      path: '/publish',
      name: 'publish',
      component: () => import('@/views/PublishView.vue'),
      meta: { requiresAuth: true },
    },
    {
      path: '/login',
      name: 'login',
      component: () => import('@/views/LoginView.vue'),
      meta: { guestOnly: true },
    },
    {
      path: '/profile',
      name: 'profile',
      component: () => import('@/views/ProfileView.vue'),
      meta: { requiresAuth: true },
    },
    {
      // 刻意不设 guestOnly：见本任务开头第 2 点
      path: '/admin/login',
      name: 'admin-login',
      component: () => import('@/views/admin/AdminLoginView.vue'),
    },
    {
      path: '/admin',
      component: () => import('@/views/admin/AdminLayout.vue'),
      meta: { requiresAdmin: true },
      children: [
        { path: '', redirect: { name: 'admin-dashboard' } },
        {
          path: 'dashboard',
          name: 'admin-dashboard',
          component: () => import('@/views/admin/DashboardView.vue'),
        },
        {
          path: 'review-queue',
          name: 'admin-review-queue',
          component: () => import('@/views/admin/ReviewQueueView.vue'),
        },
        {
          path: 'appeals',
          name: 'admin-appeals',
          component: () => import('@/views/admin/AppealQueueView.vue'),
        },
        {
          path: 'users',
          name: 'admin-users',
          component: () => import('@/views/admin/UserManageView.vue'),
        },
      ],
    },
    { path: '/:pathMatch(.*)*', redirect: '/' },
  ],
})

router.beforeEach(async (to) => {
  const userStore = useUserStore()

  if (to.meta.requiresAuth && !userStore.isAuthenticated) {
    return { name: 'login', query: { redirect: to.fullPath } }
  }

  if (to.meta.requiresAdmin) {
    if (!userStore.isAuthenticated) {
      return { name: 'admin-login', query: { redirect: to.fullPath } }
    }
    // 刷新页面后 profile 已不在内存里，先按令牌拉一次再判定，否则会把管理员误判成普通用户
    if (!userStore.profile) {
      try {
        await useAuth().loadProfile()
      } catch {
        // 多为 401，拦截器已清理登录态并跳向对应登录页；这里只决定去向
        return { name: 'home' }
      }
    }
    if (!isAdmin(userStore.profile?.role)) {
      pushToast('无权访问管理后台', 'error')
      return { name: 'home' }
    }
  }

  if (to.meta.guestOnly && userStore.isAuthenticated) {
    return { name: 'home' }
  }
  return true
})

export default router
```

- [ ] **Step 2: 改 `src/main.ts` 的 401 回调按路径分叉**

同一个 401 出口要分流到两个登录页：管理端路径下跳 `/admin/login`，其余跳 `/login`。判断依据是**当前路径前缀**，不能在 `http.ts` 里 `useUserStore`/`useRouter`（既有循环依赖约束，spec 5.3）。

```ts
import { createPinia } from 'pinia'
import { createApp } from 'vue'

import '@unocss/reset/tailwind.css'
import 'virtual:uno.css'
import './styles/main.css'

import App from './App.vue'
import { setUnauthorizedHandler } from './api/http'
import router from './router'
import { useUserStore } from './stores/user'

const pinia = createPinia()
const app = createApp(App).use(pinia).use(router)

// 401 的唯一出口：既清 localStorage（拦截器内做），也重置 Pinia 内存态，否则
// 已失效令牌会继续以「已登录」的身份放行路由守卫与页面（T-12 E）。
const userStore = useUserStore(pinia)
setUnauthorizedHandler(() => {
  userStore.signOut()
  const current = router.currentRoute.value
  // 管理端与学生端各有一个登录页：按路径前缀分叉，且只在不是本区登录页时才跳，
  // 避免两个登录页互相跳转（spec 5.3 重定向环防护）
  const adminArea = current.path.startsWith('/admin')
  const loginName = adminArea ? 'admin-login' : 'login'
  if (current.name !== loginName) {
    void router.replace({
      name: loginName,
      query: adminArea ? { redirect: current.fullPath } : {},
    })
  }
})

app.mount('#app')
```
